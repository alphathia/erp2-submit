## P004

- **Section:** 4.2.4 Diagnosing, Complexity, and Fixing of Bug Patterns

- **Relevance:** challenge

- **Text:**

> Missing Corner Cases is the only category reported as being quite hard to diagnose by respondents (score > 3). This result could be expected since the Missing Corner Cases category encompasses code that will compile correctly, but break unit tests, as highlighted by one of the participants: "It is a risk to become complacent to LLM code generation because sometimes code looks reasonable (in this case). Still, you might be unaware of all the ways it could fail".
