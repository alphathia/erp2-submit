## P002

- **Section:** VI. DISCUSSION > A. On Results

- **Relevance:** benefit

- **Text:**

> The results of this study show two interesting findings when it comes to the selection of LLMs for MALLMs for GUI test generation. Firstly, if the MALLM is intended to generate tests for a specific application, the best result is achieved when applying the same LLM to all agents. However, and secondly, if the MALLM is intended to be generally applicable to different websites, using different LLMs as different agents provides the best result.
