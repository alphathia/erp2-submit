# Raw Passages — doi:10.1002/spe.3432


## P001

- **Section:** Abstract

- **Relevance:** capability_claim

- **Text:**

> This tool, called NoCodeGPT, instruments the prompts sent to the language model with useful contextual information (e.g., the files that need to be modified when the user identifies and requests a bug fix). It also saves the files generated by the language model in the correct directories.


## P002

- **Section:** 4.4 Participants' Perceptions

- **Relevance:** challenge

- **Text:**

> The main negative point pointed out by participants was the delay in responses during interactions with the prompts (14 participants), as commented by the following participants: NoCodeGPT at times takes too long to respond.


## P003

- **Section:** 3.1 Main Features

- **Relevance:** benefit

- **Text:**

> NoCodeGPT also implements a simplified version control system for the code generated with the assistance of GPT. This allows users to easily restore a previous version if GPT starts generating invalid code that does not comply with the system specifications.
